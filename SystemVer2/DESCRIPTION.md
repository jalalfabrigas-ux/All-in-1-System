# Beginner System Ideas

## 1. Age Calculator System

User enters birth year → program calculates age.

Concepts:

* input
* subtraction
* variables

Example:

```text id="r3n9vo"
Birth Year: 2008
Current Age: 18
```

## 2. BMI Calculator System

Calculates body mass index.

Uses:

* formula
* double
* if-else

Formula:

BMI = \frac{\text{weight}}{\text{height}^2}
